# ADR-0004：IR Schema 版本化 + 误差参数 provenance 分级

- 状态：Accepted（2026-09-14）
- 背景：V0.1 的预测可信度完全建立在输入误差参数之上，而初期参数只能来自厂商手册（偏乐观）。冷启动阶段（R1 风险）若无来源标注，客户无法区分"手册说 1mm"与"我们实测 4mm"，产品可信度归零。同时 IR 是双运行时唯一契约，必须可演进。

## 备选方案

| 方案 | 结论 |
|---|---|
| A. 误差参数不带来源，报告统一口径 | 隐患最大：datasheet 偏乐观导致系统性高估性能，且无法定位该信谁 |
| B. 来源仅作展示字段，不参与计算 | 改进有限：可信度不进入判定逻辑等于没有 |
| **C. provenance 四级（datasheet/literature/measured/calibrated）作为强校验字段，并参与结果分级** | **采纳** |

## 决策

- Asset Registry 中每个误差参数必须携带 `provenance` 枚举，缺失即导入失败（数据质量强校验）。
- 内核输出携带本次判定使用的**最低 provenance 水位**；含 datasheet 级输入的结果在 Verification Matrix 与报告中显式标注"待实测确认"。
- IR Schema 带 `schemaVersion`（语义化版本）：破坏性变更升主版本，双版本共存一个过渡期；历史证据永远绑定其生成时的 schema/内核/模型版本。
- 模型（传感器/机器人误差模型、校准结果）生命周期：`DRAFT → TESTING → ACTIVE → DEPRECATED`，版本切换即回滚，不做原地修改。

## 后果

- 正面：冷启动期诚实呈现可信度边界；长期成为数据资产分级的骨架（calibrated 级即 Real2Sim 成果）。
- 负面：种子数据整理成本上升（每个参数都要标来源）；报告逻辑多一层分级。
- 依赖：M0 种子资产任务按此执行；literature 级先验数据集作为持续建设项。
